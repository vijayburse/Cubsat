# Cubsat

A CubeSat (2U) satellite project covering CAD design, structural analysis, and documentation.

## Contents

- **satellite parts/** - SolidWorks CAD models (SLDPRT/SLDASM), STL files, STEP files, and renderings of satellite assemblies and components (frame, solar panels, antenna deployment, plates)
- **step files/** - Neutral STEP format CAD models for interoperability
- **ansys results/** - ANSYS Workbench structural analysis project (model analysis of the CubeSat)
- **battery recycling/** - Battery recycling design and ANSYS analysis
- **satelite doc files/** - Architecture diagram and power budget documentation

## Purpose

Design and structural verification of a 2U CubeSat, including solar panels, antenna deployment mechanisms, and internal components, validated with FEA analysis in ANSYS.
